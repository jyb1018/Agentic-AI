# 학습 도우미 워크플로우

1. 질문 구체화
  - 무엇이 궁금한지 좁힙니다
2. 판단 
  - 무엇이 필요한가 판단합니다
  - 내 강의 노트 / 지난 학습 노트 이력 / 강의안 / 웹 자료 를 검색합니다.
3. 조사 서브에이전트 생성
  - 판단 결과에 따라 웹 조사 또는 로컬 조사 를 진행합니다
4. 1차 답변 생성 서브에이전트 생성
  - 조사 결과를 수강생 상황에 맞는 답으로 정리하는 서브에이전트로부터 1차 답변을 받습니다.
5. 적절성 검토 서브에이전트
  - 과도한 정보이거나 엉뚱한 정보는 아닌지 판정하는 서브에이전트로부터 판정합니다.

## 1단계 — 질문 구체화

사용자가 무엇이 궁금한지를 좁힙니다.

## 2단계 — 조사

researcher 를 호출하여 웹 조사 또는 로컬 조사를 맡깁니다.

## 3단계 — 1차 답변 생성

drafter 를 호출하여 1차 답변을 생성해 받아옵니다. researcher 로 부터 받은 조사 결과를 전달하고, 1차 답변을 받습니다.

## 4단계 — 적절성 검토

reviewer를 호출하여 적절성을 검토하고 과도한 정보이거나 엉뚱한 정보인지의 판정을 받아옵니다.

## 5단계 — 통합과 문서화 (메인 에이전트가 직접 답하고, 노트 저장만 임시 서브에이전트에 병렬로 맡깁니다)

여기에 최종 답변을 어떻게 전달하는지, 학습 노트를 어디에 어떤 이름으로 저장하는지 씁니다.

여기에 저장 직후 훅이 무엇을 하는지(규격 검사와 목록 갱신), 스킬이 훅을 부르지 않는 이유, 훅이 규격 위반을 돌려주면 어떻게 하는지를 씁니다.

## 완료 확인

여기에 워크플로우가 끝났을 때 무엇을 보고할지 씁니다.

## 하지 않을 일

여기에 이 순서를 어길 때 생기는 일을 막는 금지 사항을 씁니다. 학습 노트를 어디 밖에 저장하지 않는지, 이전 노트를 지우거나 덮어쓰지 않는다는 것, INDEX.md를 직접 고치지 않는다는 것을 포함합니다.

- 학습 노트는 프로젝트 디렉토리 안에 저장합니다.
- 이전 노트를 지우거나 덮어쓰지 않습니다.
- INDEX.md를 직접 고치지 않습니다.
